# Безопасность SC Trade

SC Trade is a small overlay for Star Citizen made by one person. This file says what the program does on your computer, how you can check that yourself, what the published checksums and the tests of this repository do **not** prove, and how to report a security problem. The rest of the file is in Russian, like the guide in the README.

---

## Что программа делает на компьютере

- **Файлы.** Программа открывает только свои файлы: базу `sctrade.db`, её резервные копии, базу демо-рейса `demo.db` (заполняется на время демо и очищается после него), лог и файлы-флажки. Они лежат в `%APPDATA%\com.sctrade.app`; флажок `portable.flag` и копия лога — рядом с `sc-trade.exe`, если ты сам положил туда флажок. У окна программы нет разрешения на файловую систему.
- **Сеть.** Один адрес: `api.uexcorp.uk`, только чтение справочных данных и цен. Само окно не может загрузить ничего с другого адреса — ни скрипт, ни картинку, ни шрифт: это запрещает политика окна (CSP).
- **Клавиатура.** Пока в настройках назначена хотя бы одна клавиша, Windows вызывает функцию перехвата программы на каждое нажатие. Для неназначенной клавиши функция сразу возвращается и ничего не запоминает; любое нажатие передаётся дальше, игра получает его как обычно. Программа не посылает нажатий и кликов.
- **Чужие процессы.** Программа не читает память игры, не внедряет код и не открывает описатели чужих процессов. Она только спрашивает у Windows, какому процессу принадлежит активное окно.
- **Обновления.** Программа ничего не скачивает и не обновляет себя сама.
- **Установщик.** Ставит программу для текущего пользователя, без прав администратора. Пишет в реестр запись об удалении и папку установки, создаёт ярлыки. Если в системе нет WebView2, скачивает его установщик с сайта Microsoft. При удалении спрашивает, убирать ли данные.

То же самое, подробнее и с оговорками, написано в разделе «Чего программа не делает» в [README](README.md).

## Как проверить самому

| Что | Где смотреть | Какой тест это держит |
|---|---|---|
| Разрешения окна: нет диска, один адрес в сети | `src-tauri/capabilities/default.json` | `tests/release/permissions.test.ts` |
| Окно не грузит ничего с чужих адресов | `src-tauri/tauri.conf.json`, раздел `app.security.csp` | `tests/release/csp.test.ts` |
| Нет вызовов, которыми посылают нажатия и клики | `src-tauri/src` | `tests/release/no-synthetic-input.test.ts` |
| Что делает установщик сверх стандартного шаблона Tauri | `src-tauri/installer` (наши правки помечены `; SC TRADE …`) | `tests/release/installer.test.ts` |

Собрать программу из исходников и прогнать тесты:

```bash
npm ci
```

```bash
npm test
```

```bash
npm run tauri build
```

Сеть можно проверить и без исходников: в «Мониторе ресурсов» Windows или в Wireshark у `sc-trade.exe` должен быть один удалённый адрес — `api.uexcorp.uk`.

## Чего не доказывают SHA-256 и тесты

- **Контрольная сумма** говорит одно: файл у тебя тот же, что выложен. Она не говорит, что в файле нет вреда. Бери сумму там, где не мог подменить её тот, кто подменил файл: на странице релиза в GitHub, а не рядом с файлом на стороннем сайте.
- **Файл не подписан.** Windows SmartScreen может предупредить о запуске. Подписи, которая связала бы файл с автором, сейчас нет.
- **Тесты проверяют исходники**, а не файл, который ты скачал. Связать их может только твоя собственная сборка. Сборка не воспроизводится байт в байт, поэтому сумма твоего файла не совпадёт с суммой выложенного.
- **Тест разрешений ограничивает окно**, то есть страницу программы. Код на Rust рядом с ним (перехват клавиш, работа с окном, резервные копии) этим списком не ограничен: его нужно читать, он в `src-tauri/src`.
- **Зависимости** (Tauri, его плагины, пакеты npm и Cargo) автор построчно не проверял. Их версии закреплены в `package-lock.json` и `src-tauri/Cargo.lock`.

## Как сообщить об уязвимости

- Напиши закрытое сообщение через GitHub: вкладка **Security** репозитория → **Report a vulnerability**.
- Если этой кнопки нет, открой обычный issue без подробностей («нашёл проблему безопасности, как связаться?») — автор ответит и договорится о закрытом канале.
- Не выкладывай подробности публично, пока исправление не вышло.
- Что полезно приложить: версия программы, что ты сделал, что произошло и чего ты ожидал.

Программу делает один человек в свободное время. Обещать срок ответа он не может, но на сообщения о безопасности отвечает в первую очередь.
