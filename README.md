# SC Trade

Личный дневник цен и помощник по торговым маршрутам для Star Citizen. Программа живёт небольшим окном поверх игры.

## Что это

- Ты вводишь цены, которые видишь на терминалах в игре. Программа хранит их как дневник, отмечает, насколько они свежие, и считает выгоду маршрутов.
- UEX (UEX Corp) служит справочником: списки терминалов, товаров и кораблей и общие цены. Справочные цены нужны там, где своих ещё нет.
- Свои цены важнее справочных: пока своя цена не стала холодной, расчёт идёт по ней, а не по справочной.
- Всё считается на твоём компьютере. В сеть программа ходит только за данными UEX.

## Чего программа не делает

- Не читает память игры и ничего не внедряет в чужие процессы: в коде нет ни одного вызова, которым читают чужую память или внедряют код, и ни один описатель (handle) чужого процесса не открывается.
- Не нажимает клавиши и не кликает за игрока: в коде программы нет вызовов, которыми посылают нажатия или клики. Функция оконной библиотеки, которая при отказе Windows в фокусе посылает нажатие Alt, не вызывается, и это закреплено тестом. Клавиатуру окно получает только от твоего клика по текстовому полю или по кнопке, которая открывает ввод («+ цена», «Купил» и «Продал» в раскрытой строке): пока курсор над полем или такой кнопкой, окно можно активировать кликом, как любое другое. Остальные кнопки и строки окно не активируют. Если клик пришёлся раньше, чем окно стало активируемым, программа один раз просит Windows сделать окно активным и при отказе ничего больше не делает.
- Клавиши назначаются в настройках, по умолчанию не назначено ничего. Пока назначена хотя бы одна, Windows вызывает функцию перехвата программы для каждого нажатия любой клавиши. Для клавиши, которая не назначена, функция сразу возвращается: она не читает состояние Ctrl, Alt и Shift и ничего не запоминает. Любое нажатие функция всегда передаёт дальше, так что игра получает его, как обычно: программа его не «съедает».
- В логах нет заголовков чужих окон, имён и номеров чужих процессов и координат курсора. Слежение за курсором — диагностика, по умолчанию оно выключено (как его включить, написано в «Если что-то не так»). Когда оно включено, в лог попадают только четыре признака «да/нет» (виден ли системный курсор, есть ли у него форма, над окном программы ли он, активно ли окно программы), время в миллисекундах, сколько длилось прежнее состояние, и при частом мерцании — число смен за последнюю секунду.
- Окно не забирает клавиатуру у игры само: клавиатура переходит к окну только на время ввода в текстовое поле и возвращается после ввода (`Esc` в поле возвращает её сразу). Возвращает она фокус тому окну, у которого он был до этого (обычно это окно игры), обычным системным вызовом. Кроме этого программа только сверяет, чьё окно сейчас активно: она спрашивает у Windows, какому процессу принадлежит активное окно (а при включённом слежении за курсором, раз в 100 мс, — и окно под курсором), и сравнивает номер процесса только с номером своего: номер чужого процесса нигде не сохраняется, не пишется в лог и не используется, чтобы открыть этот процесс. Окно игры при этом не меняется.

## Что нужно

- Windows 10 или 11, 64 бита.
- WebView2: в Windows 11 он уже есть. Если его нет, установщик скачает его сам (нужен интернет).
- Игра в режиме окна без рамки (borderless). Поверх эксклюзивного полноэкранного режима окно не рисуется.
- Интернет для данных UEX. Без него программа работает на уже загруженных данных и твоих записях.

## Установка и первый запуск

1. Запусти установщик `SC Trade_0.1.0_x64-setup.exe`. Он ставит программу для текущего пользователя и не требует прав администратора. Папка по умолчанию — `%LOCALAPPDATA%\SC Trade`: на странице выбора папки её можно сменить, а если программа уже стояла, установщик предлагает прежнюю. Ярлык в меню «Пуск» создаётся. Ярлык на рабочий стол («Добавить ярлык на рабочий стол», в английской версии «Create desktop shortcut») и запуск программы предлагаются на последней странице установщика.
2. Файл не подписан, поэтому Windows может показать предупреждение SmartScreen. Решение о запуске за тобой.
3. После запуска появляется мини-строка в углу экрана и значок SC Trade в трее; меню значка: «Показать панель» и «Выход». На панели задач у окна кнопки нет. В Windows 11 значок может оказаться в области скрытых значков за стрелкой «^».
4. При первом запуске программа загружает справочники и цены UEX: в окне написано «Загрузка справочника UEX…». Цены грузятся дольше справочника; ход виден в шапке («UEX 23/57»), а таблица терминала заполняется по ходу загрузки. Если загрузка не удалась, окно показывает ошибку и кнопку «Повторить»; оно разворачивается само, даже если мини-строка выключена. Позже при запуске справочник обновляется, если ему больше суток, а цены — если им больше часа; пока программа запущена, цены обновляются раз в час.
5. Выбери корабль: шестерёнка в шапке окна → группа «Корабль и поиск» → «Корабль» (список появляется после загрузки справочника) или вручную «Вместимость, SCU». Пока вместимость равна нулю (так по умолчанию), ROI не считается: столбец ROI в таблице пуст (подсказка в его заголовке: «Укажи корабль в настройках — без вместимости ROI не считается»), а в секции «Варианты» написано «Укажи корабль в настройках» с кнопкой «Открыть настройки». В той же группе — «Система» и «Бюджет, UEC».

Обновление: закрой программу («Выход» в меню значка) и запусти новый установщик. Он увидит установленную версию и предложит «Удалить перед установкой» или «Не удалять» (в английской версии «Uninstall before installing» / «Do not uninstall»). Данные при этом остаются: они лежат вне папки программы и удаляются только отметкой «Удалить данные приложения» (см. ниже).

Чтобы удалить программу, открой «Параметры» → «Приложения» → «Установленные приложения» (Windows 11) или «Приложения и возможности» (Windows 10). Окно удаления содержит отметку «Удалить данные приложения» (в английской версии «Delete the application data»). По умолчанию она не отмечена; если её отметить, будут удалены и твоя база, и резервные копии, и логи (см. «Где лежат данные»).

## Как пользоваться

### Окно

- Свёрнутое окно — мини-строка: одна строка в углу экрана (по умолчанию сверху справа). Клик по ней разворачивает окно, значок «минус» в развёрнутом окне сворачивает.
- Развёрнутое окно само сворачивается, когда курсор ушёл с него и прошло время из настройки «Сворачивать через, с» (по умолчанию 40 с, `0` — не сворачивать).
- Пока окно держит клавиатуру (после клика в поле ввода), в шапке на месте надписи «UEX …» стоит «Esc — в игру» цветом акцента, а в настройках такая плашка стоит в шапке. `Esc` в поле или клик по этой надписи возвращают клавиатуру игре; окно остаётся открытым, а обновление цен клик не запускает (и сразу после того, как надпись исчезла, клик по «UEX …» на долю секунды ничего не делает: второй клик двойного не должен обновить цены). Остальные кнопки шапки при этом не сдвигаются.
- Окно двигается за зацеп — точки слева в строке. Перетащенное окно привязывается к верхнему краю и к левой или правой стороне экрана (к той, что ближе), поэтому развёрнутое окно раскрывается вниз от места, где была строка. Нижние углы можно выбрать в «Настройки» → «Окно» → «Угол экрана». Замок рядом с настройками закрепляет окно: закреплённое окно за зацеп не двигается.
- Без мини-строки (настройка «Показывать мини-строку») свёрнутое окно скрыто: его открывает значок в трее или назначенная клавиша.
- Закрыть программу: пункт «Выход» в меню значка в трее или кнопка «Выход» в «Настройки» → «Данные».
- Вторая копия не запускается: повторный запуск (например, из меню «Пуск») сразу закрывается сам, а в уже работающей программе открывается панель, как по пункту «Показать панель» в меню значка.

### Настройки

Настройки открывает значок шестерёнки в шапке. Шесть групп:

- «Корабль и поиск»: корабль, «Вместимость, SCU» (от неё зависит объём закупки и сам расчёт ROI), «Система», «Бюджет, UEC». У полей вместимости, бюджета и всех полей группы «Расчёт маршрутов» есть подсказка: что поле меняет в расчёте.
- «Свежесть цен»: до какого возраста цена считается горячей, тёплой и остывающей — поля «Горячая до, мин», «Тёплая до, мин» и «Остывает до, мин» (по умолчанию 60 / 180 / 240 минут: это границы возраста, а не длительности по очереди); старше последней границы цена считается холодной.
- «Расчёт маршрутов»: «Скорость квантума, тыс. км/с», «Накладные на рейс, мин», «Накладные на пустой перелёт, мин», «Число вариантов», «Полное пополнение склада, мин» и «Выделять ROI от, %» (порог выделения строк таблицы, см. ниже).
- «Клавиши»: три необязательные клавиши (см. «Клавиши»).
- «Окно»: «Угол экрана», «Ширина окна, px», «Сворачивать через, с», «Прозрачность», «Показывать мини-строку».
- «Данные»: «Уровень журнала», «Открыть папку логов», «Обновить справочник», «Выход».

### Локация

- В поле «Локация…» набери три буквы названия терминала и нажми `Enter` (берётся верхний вариант) или выбери стрелками. Это только меняет, какой терминал показан.
- В списке у каждого варианта приглушённо подписано, где терминал: система и планета (или луна, если терминал на ней). Так отличаются терминалы с одним названием из разных систем, например «Stanton Gateway». Искать можно и по названию системы. Полное место видно в подсказке у локации в шапке, у заголовка секции «Терминал» и у терминала в строке списка вариантов маршрута.
- Кнопка «Я здесь» (она появляется, когда показан не тот терминал, где ты находишься) делает показанный терминал текущей локацией. Текущая локация меняется и сделкой: записанные «Купил», «Продал» и продажа без закупки делают терминал сделки текущей локацией (если запись не удалась, локация остаётся прежней). Ещё текущую локацию меняет «Прилетел», когда задана цель: см. «Рейс». От текущей локации считаются маршруты.

### Таблица терминала

- Секция «Терминал» показывает товары выбранного терминала. Переключатель «Купить · N» / «Продать · N»: что здесь можно купить и что здесь можно продать. Переключатель, кнопка с лупой и кнопка «+ цена» стоят в заголовке только развёрнутой секции «Терминал»; у свёрнутой в заголовке только слово «Терминал» и название терминала.
- Клик по строке раскрывает её. В раскрытой строке два поля — цена (UEC за SCU) и количество (SCU) — и кнопки: «Где продать» и «Купил» на стороне покупки, «Где купить» и «Продал» на стороне продажи. Что и когда записывается — в двух следующих пунктах.
- В поле цены стоит показанная цена (своя или справочная); пока ты её не тронул, она приглушена, если не твоя свежая (справочная UEX или твоя остывшая). Её можно поправить, а не набирать заново. Количество записывается отдельно, цену для этого трогать не нужно: запишется показанная цена, которая стоит в поле. Если цены нет совсем, поле цены обязательно.
- Первый клик в поле цены или количества (в раскрытой строке, в форме сделки и в быстром вводе) выделяет число целиком: набранное заменит его, стирать ничего не нужно. Второй клик в то же поле ставит курсор туда, куда ты кликнул, — так правят одну цифру. Переход в поле по `Tab` тоже выделяет число. Выделение ничего не записывает, и приглушённая цена остаётся приглушённой, пока ты её не изменил.
- `Enter` в любом из двух полей означает «я это вижу сейчас»: записывается цена, которая стоит в поле (так показанная справочная цена подтверждается как твоя, а твоя освежается), и количество, только если ты его набрал; число, которое просто стоит в поле количества, не отправляется. Уход из строки кликом записывает только изменённое: набранную цену, если она отличается от твоей (равная показанной справочной считается подтверждённой и записывается), и набранное количество, если оно отличается от стоящего.
- Кнопки «Купил» и «Продал» открывают под строкой форму сделки с готовыми количеством и ценой, и курсор сразу стоит в форме: после «Купил» — в количестве, после «Продал» — в цене; число выделено, его можно сразу набирать заново. Клик по самой строке (раскрытие) курсор никуда не ставит. Цена, которая не твоя (справочная UEX или твоя остывшая), стоит в форме приглушённой, как в поле строки, пока ты не набрал в поле цены своё число; запись от этого не меняется: `Enter` запишет цену, которая стоит в поле. Чья цена и насколько она свежая — на значке в раскрытой строке над формой.
- Заголовки «Товар» и «ROI» таблицы — кнопки. Клик по «ROI» ставит наверх строки с лучшим ROI (у кого ROI нет — в конец), повторный клик переворачивает порядок, клик по «Товар» возвращает порядок по умолчанию (по названию товара). Стрелка в заголовке показывает, по какому столбцу отсортировано; выбор помнится, пока программа открыта. Сортировка меняет только порядок строк: раскрытая строка остаётся раскрытой, набранный в ней текст не пропадает. Пока курсор стоит в поле таблицы (цена или количество в строке, форма сделки), строки не переезжают, даже если после записи цены их ROI изменился: новые числа видны сразу, а порядок применится, когда курсор уйдёт из поля.
- Пока идёт рейс, на стороне «Продать» товары из трюма стоят в таблице первыми (в порядке груза, при сортировке по «ROI» — по ROI внутри этой группы) и помечены квадратом с точкой и количеством SCU у названия; в подсказке метки написано, по какой цене товар куплен. На стороне «Купить» и без рейса ничего не меняется.
- Кнопка «+ цена» открывает быстрый ввод: товар, цена, количество, `Enter`. Курсор сразу стоит в поле «Товар»: кликнул по кнопке — и печатай. Если запись не принята, под строкой написано почему («Выбери товар», «Цена — целое число больше нуля», «Количество — целое число от нуля»); сообщение остаётся, пока поле отмечено красным.
- Значок рядом с ценой говорит, чья она и насколько свежая. Закрашенный квадрат — твоя цена: горячая, тёплая, остывает или холодная. Пустой квадрат — данные UEX. Пороги свежести (по умолчанию 60 / 180 / 240 минут) меняются в «Настройки» → «Свежесть цен».
- Треугольник у цены показывает, куда сдвинулась твоя цена с прошлой записи. Зелёный — сдвиг в твою пользу, красный — против.
- Восклицательный знак у цены: цена далеко от истории UEX, проверь цифру.

### Выгода в таблице и «что везти сюда»

- В таблице есть столбец ROI — лучшая выгода для этого товара. На стороне «Продать» это лучший вариант «купить где-то и привезти сюда», на стороне «Купить» — лучший вариант «купить здесь и отвезти куда-то». Считается по данным на твоём компьютере, без запросов к UEX. Подсказка у числа говорит, откуда или куда везти и по каким ценам.
- Ячейка ROI пуста, если для товара нет варианта, который окупается при текущих фильтрах (система, бюджет, вместимость, наличие товара). Пока корабль не выбран (вместимость 0), пуст весь столбец: см. шаг 5 в «Установка и первый запуск». ROI выше 999 % показан как «999+», точное число — в подсказке.
- Строка, у которой ROI не ниже порога, выделена цветной полосой слева. Порог — «Настройки» → «Расчёт маршрутов» → «Выделять ROI от, %»: целое число от 0 до 500, по умолчанию 50. `0` выделяет каждую строку, которая в плюсе. Когда строка впервые переходит порог после ввода цены, она один раз вспыхивает.
- Клик по числу ROI в строке открывает секцию «Варианты» для этого товара. На стороне «Продать» она называется «Где купить <товар> для <терминал>», на стороне «Купить» — «Куда везти <товар> с <терминал>». Заголовок после клика по ROI заканчивается ценой строки (твоей, а если своей нет — справочной): « · продажа 5 088» на стороне «Продать», « · покупка 2 240» на стороне «Купить» (так же после кнопок «Где продать» и «Где купить» в раскрытой строке). У поиска по всем товарам цены в заголовке нет.
- Кнопка с лупой в заголовке секции «Терминал» (рядом с «+ цена») ищет сразу по всем товарам терминала. Подсказка кнопки на стороне «Продать»: «Что везти сюда: лучшие варианты по всем товарам, которые здесь покупают»; на стороне «Купить»: «Куда отсюда: лучшие варианты по всем товарам, которые можно купить здесь». Секция «Варианты» после этого называется «Где купить для <терминал>» (сторона «Продать») или «Куда везти с <терминал>» (сторона «Купить»).

### Маршрут

- Кнопка «Маршрут» показывает лучшие варианты из текущей локации в секции «Варианты». Если текущая локация не указана, программа просит сначала нажать «Я здесь».
- Сортировка: «UEC/ч» или «ROI». «и рядом» есть только у поиска «Куда везти …»: он добавляет закупку на других точках той же планеты. «все товары» — искать по всем товарам точки, когда варианты показаны для одного товара.
- Клик по варианту раскрывает его: объём, вложение, прибыль, худший исход, время, число твоих рейсов, расстояние.
- ROI окрашен по ступеням: от 30 % и выше — зелёный, от 15 % — светло-зелёный, от 5 % — оранжевый, от 0 % — серый, ниже нуля (убыток) — красный.
- Кнопка «Цель» в раскрытом варианте делает его целью рейса. «Снять цель» (или крестик в заголовке секции «Рейс») убирает цель.

### Рейс

- Первая покупка («Купил») начинает рейс и запускает таймер. Секция «Рейс» показывает груз, три фазы — «Погрузка», «Полёт», «Выгрузка» — и вложения, выручку, прибыль, ROI и UEC/ч (до конца рейса это ожидаемый результат). UEC/ч в секции и в мини-строке («≈ 273k/ч») — одно и то же число, и оно показано только когда известно время рейса: известно время полёта до цели (по твоей медиане или по расстоянию) или отмечен «Прилетел» (пока это последняя из отметок «Взлетел» / «Прилетел»: после нового «Взлетел» время снова неизвестно). Пока время неизвестно, в секции на месте UEC/ч прочерк, а в мини-строке числа нет; прибыль и ROI показаны. У каждого товара в трюме мини-строка (и заголовок свёрнутой секции «Рейс») говорит количество и цену, по которой он куплен («MEDS 120 SCU по 2 115»; когда товаров несколько, без «SCU»), а подсказка к грузу даёт строку на товар с ожидаемой ценой продажи в точке цели.
- Кнопки «Взлетел» и «Прилетел» отмечают фазы. Они есть и в мини-строке, и на них можно назначить клавиши. «Прилетел» при заданной цели показывает терминал цели в шапке и в секции «Терминал» и делает его текущей локацией (стороной «Продать», когда в трюме груз; если на этой стороне у терминала нет строк — стороной «Купить»). Цель при этом не снимается: она остаётся до конца рейса. Без цели отметка ничего не переключает.
- «Продал» продаёт товар из трюма. Продажа последнего товара закрывает рейс и сбрасывает цель. В тот же момент окно говорит итог рейса: «Рейс закрыт: +73 400 · 369k/ч · ROI 15%» — прибыль со знаком, UEC в час и ROI, те же числа, что в строке этого рейса в «Истории»; нет времени рейса или нет вложений — этого числа в строке нет. Итог виден 8 секунд в строке под шапкой и в мини-строке, рейс в убыток — красным. Отказ записи («В трюме только 120 SCU») итогом не закрывается: он остаётся под строкой.
- «Груз потерян» закрывает рейс как потерянный и списывает груз (с подтверждением). Итог: «Рейс закрыт: груз потерян, -478 600».
- Продажа без закупки: если товара нет в учтённом трюме (он куплен до запуска программы, добыт или собран), «Продал» не отказывает, а записывает доход без закупки. Количество вводишь ты, вложение — 0, ROI не показывается. Такая запись не трогает идущий рейс, попадает в историю («продажа без закупки») и в заработок сессии, но не в рейтинг маршрутов и не в медианы времени. Окно говорит: «Доход записан: +12 000» (в мини-строке три секунды, чтобы не прятать кнопки отметок идущего рейса).
- Пока идёт рейс без цели, в заголовке секции «Рейс» на месте слов «цель не выбрана» стоит кнопка «Цель: <терминал>» с названием терминала, который показан в окне: клик делает его целью рейса, как кнопка «Цель» у варианта. На терминале, где сделана первая покупка рейса, кнопки нет.
- В секции «Рейс» для товара из трюма, у которого на показанном терминале есть твоя не холодная цена продажи, программа сравнивает «продать здесь» с вариантами «лететь дальше» (прибыль, UEC/ч, время в пути).

### Сменил сервер

- Кнопка со стрелками в шапке окна. Нажимай её, когда сменил сервер игры: цены на новом сервере могут быть другими. После подтверждения («Да, сменился») все твои цены до этой минуты считаются холодными, и расчёт опирается на справочные.
- Кнопка спрашивает подтверждение, чтобы случайный клик не охладил все цены.

### Цены UEX

- Надпись «UEX 12 мин» в шапке показывает, как давно загружены цены. Это кнопка: клик запускает обновление цен сейчас, а надпись на время обновления показывает его ход («UEX 23/57»). Надпись «UEX офлайн 3 ч» (цветом предупреждения) значит, что последнее обновление не удалось, а число — возраст тех цен, на которых программа считает сейчас (в том же виде, что у «UEX 12 мин»); полная фраза с датой — в подсказке. Если загруженных цен нет совсем, надпись такая: «UEX недоступен».
- Раз в час цены обновляются сами, пока программа запущена. Если прошлое обновление справочника не удалось, клик по надписи и часовое обновление сначала повторяют справочник, потом обновляют цены. Кнопка «Обновить справочник» в «Настройки» → «Данные» обновляет списки терминалов, товаров и кораблей.

### Мои маршруты и заработок за сессию

- Секция «Мои маршруты» показывает твои рейсы: «Маршруты» (по UEC в час), «История» (все рейсы, новые сверху), «Сессии».
- Подписи в «Истории»: потерянный рейс без продаж — «GOLD: груз потерян» (красным), идущий без продаж — «GOLD: идёт», рейс с несколькими товарами, который что-то продал, — «смеш.: откуда → куда» (от терминала первой покупки до терминала последней продажи; все товары — в подсказке строки). Продажа без закупки — «продажа без закупки», как раньше.
- В «Маршруты» попадают только простые рейсы: один товар, куплен в одной точке и продан в другой. Рейс с несколькими товарами в рейтинг маршрутов не входит; он есть в «Истории» и учтён в заработке сессии.
- Каждый список секции («Маршруты», «История», «Сессии») показывает восемь строк, чтобы окно не росло вниз; остальные (в истории — старые рейсы) открываются колесом мыши внутри списка, строка заголовков столбцов при этом остаётся на месте.
- Заголовки числовых столбцов таблицы «Маршруты» (UEC/ч, Рейс, Время, Прибыль, ROI) — кнопки: клик ставит наверх лучшие маршруты по этому столбцу (по времени — самые быстрые), повторный клик переворачивает порядок, стрелка в заголовке показывает столбец и направление; маршруты без значения всегда внизу, выбор помнится, пока программа открыта.
- Сессия — это серия записей без пауз дольше двух часов. Прибыль текущей сессии видна в мини-строке без рейса («сессия +1,24M») и в заголовке свёрнутой секции «Мои маршруты» вместе с доходом в час. Когда секция развёрнута, сессии видны на вкладке «Сессии»; сессия, в которой не было ни одного рейса и прибыль нулевая (ты только вносил цены), в списке не показана, а сессия только с продажей без закупки показана.
- История рейсов хранится бессрочно, пока её не очистят: «Настройки» → «Данные» показывают, сколько в ней рейсов и с какой даты, и дают кнопки «Очистить старше 30 дней» (по времени окончания рейса) и «Очистить всю историю», каждая сначала спрашивает подтверждение с числом рейсов. Очистка удаляет только завершённые и потерянные рейсы: идущий рейс и твои цены остаются (после очистки список «Сессии» показывает только сессии, в которых остались рейс или прибыль), а резервная копия, сделанная при запуске, содержит историю до очистки.

## Обозначения

Что значат знаки и подписи в окне. У большинства из них есть и подсказка: наведи курсор.

- Квадрат у цены — чья цена и насколько она свежая. Закрашенный — твоя: красно-оранжевый — горячая, янтарный — тёплая, голубой — остывает, серо-голубой — холодная. Пустой квадрат с серо-голубой рамкой — цена из UEX. Полная подпись («моя · 40 мин», «UEX · 2 д») стоит в раскрытой строке; пороги свежести — «Настройки» → «Свежесть цен».
- Треугольник у цены — твоя цена сдвинулась с прошлой записи: вверх — выросла, вниз — упала. Зелёный — в твою пользу (выросла цена продажи или упала цена покупки), красный — против. В подсказке: «было 2 300 · 2 ч назад (+50)».
- «!» у цены: цена далеко от истории UEX — меньше половины самой низкой или больше удвоенной самой высокой цены, которую UEX знает за всё время. Проверь цифру.
- «—» в столбце «SCU»: количество неизвестно — нет свежего твоего замера и нет данных UEX (твой замер, который остыл, не используется). Это не пустой склад: известный ноль пишется «0».
- «Мин–макс»: самая низкая и самая высокая цена по данным UEX за неделю; если за неделю цены нет — за месяц, потом за всё время. «= 5 500» — цена за период не менялась.
- «≈» в трёх разных местах. Перед числом в столбце «SCU» — оценка запаса по таймеру пополнения: сколько там, по расчёту, сейчас; «было 380 · 20 мин» в раскрытой строке говорит, от какого твоего замера считалось. В секции «Рейс» («≈ 66 720», «≈ 14%», «≈ 337k») — ожидаемые прибыль, ROI и доход в час идущего рейса: так будет, если груз продастся в точке цели по ожидаемым ценам; в мини-строке из этого только доход в час («≈ 273k/ч»). Перед названием в заголовке секции «Варианты» — список предварительный: он построен по тем расстояниям, что уже известны, остальные догружаются (рядом «расстояния 7/15»); у вариантов без известного расстояния (и без твоих рейсов по этой паре) пока нет ни времени, ни UEC/ч.
- «скорость выучена» / «скорость запасная» в раскрытой строке с оценкой запаса — это скорость пополнения склада, по которой считается оценка «≈». «Выучена» — по твоим замерам количества на этой паре «терминал + товар»: берётся самое быстрое пополнение между двумя соседними записями (не ближе двух минут друг к другу), где количество выросло. «Запасная» — таких замеров нет, взят максимум запаса, делённый на «Полное пополнение склада, мин» из настроек.
- «ждём» в мини-строке рейса («ждём 2 351») — ожидаемая цена продажи за один SCU первого товара из трюма в точке цели; по каждому товару она написана в подсказке груза. В секции «Рейс», когда у товара из трюма на показанном терминале есть твоя не холодная цена продажи, есть сравнение «продать здесь или лететь дальше»: строка «Здесь» (продать весь груз этого товара тут; её UEC в час — за время, прошедшее с начала рейса) и под ней таблица других покупателей со столбцами «Куда», «Цена», «Прибыль», «Ждём», «Худш.» и «Лететь». «Ждём» и «Худш.» — UEC в час всего рейса, если продать у этого покупателя по ожидаемой цене и по худшей цене её диапазона.
- «Худший» в раскрытом варианте — прибыль при худших ценах диапазона: закупка по верхней границе диапазона цены закупки, продажа по нижней границе диапазона цены продажи. У твоей цены диапазона нет, берётся она сама.
- «Время» в раскрытом варианте — время всего рейса: сам рейс плюс, если закупка идёт на другом терминале, чем тот, с которого ищутся варианты (так бывает с «и рядом»), пустой перелёт к ней. Сам рейс — это медиана твоих рейсов по этой паре, если они есть («по твоим рейсам» в подсказке), иначе расчёт по расстоянию: перелёт на скорости квантума плюс «Накладные на рейс». Пустой перелёт всегда считается по расстоянию до точки закупки на той же скорости, плюс «Накладные на пустой перелёт»; в подсказке он назван («пустой перелёт 4:10»). Времени нет, и стоит прочерк, когда для одной из нужных частей не хватает расстояния: для самого рейса — и при отсутствии твоих рейсов по паре, для пустого перелёта — всегда.
- «UEC/ч» — не одно число, а разные в разных местах. В списке «Варианты» — ожидание для варианта: прибыль по ожидаемым ценам, делённая на «Время» варианта. В секции «Рейс» и в мини-строке — оценка идущего рейса: ожидаемая прибыль всего рейса за время всего рейса (не меньше прошедшего и не меньше, чем лететь до цели). В «Маршрутах» и «Истории» — по завершённым рейсам: прибыль, делённая на время рейсов. На вкладке «Сессии» — заработок сессии: прибыль, делённая на всё время сессии от первой записи до последней, простои между записями входят.
- «?» после названия варианта: запас в точке закупки неизвестен (нет свежего твоего замера и нет данных UEX), поэтому объём варианта посчитан без него — по трюму и бюджету. Настоящий объём может быть меньше. В раскрытом варианте это же написано словами под числами «Объём», «Вложение», «Прибыль» и «Худший». Известный нулевой запас — не «?»: такой вариант в списке не появляется.
- Квадрат с точкой и число после названия товара в таблице терминала на стороне «Продать» — этот товар у тебя в трюме (идёт рейс), число — сколько SCU; такие строки стоят первыми, в подсказке написано, по какой цене товар куплен.

## Клавиши

В «Настройки» → «Клавиши» можно назначить три действия:

- «Развернуть и свернуть окно»;
- «Отметка «Взлетел»»;
- «Отметка «Прилетел»».

По умолчанию ничего не назначено. Клавишу не нужно вписывать текстом: поставь курсор в поле и нажми её, с модификаторами, если они нужны. В поле запишется её обозначение (например `F9` или `Ctrl+Alt+T`) и сразу сохранится; `Backspace` или `Delete` в поле снимают клавишу. Записывается только клавиша, которую можно назначить (список ниже). Остальные — пробел, стрелка, `CapsLock`, буква или цифра без `Ctrl` и `Alt` и так далее — не записываются: в поле остаётся прежняя клавиша, а рядом на несколько секунд написано, почему эта не подошла. `F5`, `F11`, `F12`, `Ctrl+R` и `Ctrl+Shift+R` занимает само окно, назначить их нельзя. `Enter`, `Esc`, `Tab` (с `Shift` или без), одна нажатая `Ctrl`, `Alt` или `Shift`, клавиша Win и `Alt+F4` не записываются и работают как обычно: `Enter` — как в других полях настроек (ничего особенного), `Esc` возвращает клавиатуру игре, `Tab` переходит к следующему полю. Пока курсор стоит в поле клавиши, назначенные клавиши не срабатывают (нажатие уже назначенной клавиши в поле не поставит отметку и не свернёт окно); когда курсор ушёл из полей клавиш, закрыты настройки или окно свёрнуто, они снова действуют.

Запись клавиши: `F8`, `Ctrl+Alt+T`, `Shift+F9`. Допустимы `F1`–`F24`, кроме `F5`, `F11` и `F12`, `ScrollLock`, `Pause` (сама, с `Alt` или с `Shift`, но не с `Ctrl`: Windows передаёт `Ctrl+Pause` как другую клавишу), `Insert`, `Home`, `End`, `PageUp`, `PageDown`, а также буква или цифра вместе с `Ctrl` или `Alt`. Модификаторы `Ctrl`, `Alt` и `Shift` пишутся в любом порядке и любым регистром.

- Модификаторы должны совпасть точно: клавиша `F8` не сработает, пока зажат `Ctrl`, а `Ctrl+Alt+T` — пока зажат ещё и `Shift`.
- На раскладках с клавишей AltGr Windows считает её нажатием `Ctrl+Alt`, поэтому назначенное `Ctrl+Alt+<буква>` срабатывает и от AltGr+та же буква (например, когда набираешь символ с этой клавиши в чате игры). Лучше назначать функциональные клавиши.
- Клавиша Win в записи не используется и не учитывается: нажатая вместе с назначенной клавишей, она не мешает срабатыванию (`Win+F8` сработает как `F8`).
- Одну клавишу нельзя назначить двум действиям: программа ответит «Эта клавиша уже назначена другому действию».
- Если клавиша не подошла, причина написана рядом с полем, а сохранённая клавиша остаётся на месте.
- Нажатие назначенной клавиши доходит и до игры, как любое другое.

## Если что-то не так

- Звук игры глохнет, когда окно берёт клавиатуру (ввод в поле). В настройках игры включи звук в фоне, пока окно игры не активно.
- Клик по полю ничего не дал: курсора в поле нет, клавиши идут в игру. Windows отказала окну в активации — так бывает, если кликнуть сразу, не задержав курсор над полем. Кликни по полю ещё раз. То же с кнопками «+ цена», «Купил» и «Продал»: быстрый ввод или форма откроются, но курсора в поле не будет — кликни по полю. На сенсорном экране или с пером без наведения ввод может не заработать совсем: отказ Windows программа не обходит.
- UEX не отвечает. Проверь, открывается ли сайт UEX в браузере: из некоторых сетей он доступен только через VPN. Программа при этом работает на твоих и уже загруженных данных, а в шапке написано «UEX офлайн …» с возрастом этих данных (подсказка называет и дату).
- Курсор появляется, когда крутишь камеру при развёрнутом окне. Это известное замечание: игра прячет курсор, но он продолжает двигаться, и над окном программы Windows показывает стрелку. Пока окно не нужно, держи его свёрнутым. Чтобы собрать данные для разбора, положи рядом с `sc-trade.exe` пустой файл `cursor-watch.flag` и перезапусти программу: в лог пойдёт, когда игра прячет и показывает курсор. Без этого файла слежения за курсором нет.
- Назначенные клавиши перестали срабатывать. Windows молча снимает перехват клавиш, если программа ответила на нажатие слишком поздно (так бывает, когда игра занимает все ядра). Разверни окно мышью — кликом по мини-строке или из трея: при этом клавиши применяются заново и перехват ставится снова. Можно и перезапустить программу.
- После обновления окно раскрывается вниз. Один раз перетащи его за зацеп на нужное место: положение сохранится в настройках.
- Нужен лог для отчёта об ошибке: «Настройки» → «Данные» → «Открыть папку логов». Приложи файл `sctrade.log`. В нём есть пути к папкам с именем пользователя Windows, версия Windows, размер экрана, идентификаторы терминалов и цены, названия назначенных клавиш и числовой номер окна, у которого была клавиатура до того, как её взяло окно программы; заголовков чужих окон, имён и номеров чужих процессов нет. «Уровень журнала» там же: по умолчанию `debug`. Он относится к строкам самой программы; строки сторонних библиотек (база данных, сеть, окна) попадают в лог только уровня `info` и выше, какой бы уровень ни был выбран.

## Где лежат данные

- База (настройки, твои цены, рейсы, справочник UEX): `%APPDATA%\com.sctrade.app\sctrade.db`. Рядом с ней лежат `sctrade.db-wal` и `sctrade.db-shm`: это части той же базы. Копировать базу вручную можно только при закрытой программе, и все три файла вместе.
- Резервные копии: `%APPDATA%\com.sctrade.app\backups\sctrade-ГГГГММДД-ЧЧММСС.db`. Копия делается при каждом запуске, если база уже есть. Хранятся пять последних. Время в имени — UTC.
- Логи: `%LOCALAPPDATA%\com.sctrade.app\logs\sctrade.log`. Файл ротируется при 5 МБ, всего хранится до пяти файлов. Время в строках лога местное.
- Лог рядом с программой: если рядом с `sc-trade.exe` положить пустой файл `portable.flag`, те же строки пишутся ещё и в `sc-trade.log` рядом с exe. Это не делает программу переносной: база остаётся в папке выше.
- Профиль WebView2 (кэш и данные самого окна, их создаёт WebView2): `%LOCALAPPDATA%\com.sctrade.app\EBWebView`.

## Сборка из исходников

Нужно:

- Node.js 24 и npm 11 (на них разрабатывалось; в проекте `@types/node` 24);
- Rust 1.90 или новее (поле `rust-version` в `src-tauri/Cargo.toml`), редакция 2024;
- сборочные инструменты Microsoft C++ и WebView2, как для любого приложения на Tauri 2.

Команды:

- `npm ci` — поставить зависимости;
- `npm run tauri dev` — запустить программу в режиме разработки;
- `npm test` — тесты (vitest);
- `npm run check` — проверка типов (svelte-check);
- `cargo test --manifest-path src-tauri/Cargo.toml` — тесты Rust;
- `npm run build` — сборка интерфейса (`dist`);
- `npm run tauri build` — установщик: `src-tauri/target/release/bundle/nsis/SC Trade_0.1.0_x64-setup.exe`, программа — `src-tauri/target/release/sc-trade.exe`. При первой сборке Tauri скачивает NSIS.

Интерфейс можно смотреть в браузере без Tauri и без игры (нужен установленный Edge или Chrome):

- `npm run preview:ui` — сервер просмотра и адрес страницы со списком сцен;
- `npm run preview:shot -- --scene expanded` — снимок сцены в PNG (`--help` показывает все параметры);
- `npm run preview:sweep` — прогон всех сцен и страниц галереи; в конце должно быть «all passed».
