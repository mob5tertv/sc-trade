# SC Trade

Личный дневник цен и помощник по торговым маршрутам для Star Citizen. Программа живёт небольшим окном поверх игры.

## Что это

- Ты вводишь цены, которые видишь на терминалах в игре. Программа хранит их как дневник, отмечает, насколько они свежие, и считает выгоду маршрутов.
- UEX (UEX Corp) служит справочником: списки терминалов, товаров и кораблей и общие цены. Справочные цены нужны там, где своих ещё нет.
- Свои цены важнее справочных: пока своя цена не стала холодной, расчёт идёт по ней, а не по справочной.
- Всё считается на твоём компьютере. В сеть программа ходит только за данными UEX.

## Чего программа не делает

- Не читает память игры и ничего не внедряет в чужие процессы: в коде нет ни одного вызова, которым читают чужую память или внедряют код, и ни один описатель (handle) чужого процесса не открывается.
- Не нажимает клавиши и не кликает за игрока: в коде нет вызовов, которыми посылают нажатия или клики.
- Клавиши назначаются в настройках, по умолчанию не назначено ничего. Пока назначена хотя бы одна, Windows вызывает функцию перехвата программы для каждого нажатия любой клавиши. Для клавиши, которая не назначена, функция сразу возвращается: она не читает состояние Ctrl, Alt и Shift и ничего не запоминает. Любое нажатие функция всегда передаёт дальше, так что игра получает его, как обычно: программа его не «съедает».
- В логах нет заголовков чужих окон, имён и номеров чужих процессов и координат курсора. Слежение за курсором пишет в лог только четыре признака «да/нет» (виден ли системный курсор, есть ли у него форма, над окном программы ли он, активно ли окно программы), время в миллисекундах, сколько длилось прежнее состояние, и при частом мерцании — число смен за последнюю секунду.
- Окно не забирает клавиатуру у игры само: клавиатура переходит к окну только на время ввода в текстовое поле и возвращается после ввода (`Esc` в поле возвращает её сразу). Возвращает она фокус тому окну, у которого он был до этого (обычно это окно игры), обычным системным вызовом. Кроме этого программа только смотрит за курсором: раз в 100 мс она спрашивает у Windows, какому процессу принадлежит окно под курсором и какое окно сейчас активно, и сравнивает ответ только со своим процессом (чужой процесс не опознаётся). Окно игры при этом не меняется, а в лог попадает только то, что описано в предыдущем пункте.

## Что нужно

- Windows 10 или 11, 64 бита.
- WebView2: в Windows 11 он уже есть. Если его нет, установщик скачает его сам (нужен интернет).
- Игра в режиме окна без рамки (borderless). Поверх эксклюзивного полноэкранного режима окно не рисуется.
- Интернет для данных UEX. Без него программа работает на уже загруженных данных и твоих записях.

## Установка и первый запуск

1. Запусти установщик `SC Trade_0.1.0_x64-setup.exe`. Он ставит программу для текущего пользователя и не требует прав администратора. Папка по умолчанию — `%LOCALAPPDATA%\SC Trade`: на странице выбора папки её можно сменить, а если программа уже стояла, установщик предлагает прежнюю. Ярлык в меню «Пуск» создаётся. Ярлык на рабочий стол («Добавить ярлык на рабочий стол», в английской версии «Create desktop shortcut») и запуск программы предлагаются на последней странице установщика.
2. Файл не подписан, поэтому Windows может показать предупреждение SmartScreen. Решение о запуске за тобой.
3. После запуска появляется мини-строка в углу экрана и значок SC Trade в трее; меню значка: «Показать панель» и «Выход». На панели задач у окна кнопки нет. В Windows 11 значок может оказаться в области скрытых значков за стрелкой «^».
4. При первом запуске программа загружает справочники и цены UEX: в окне написано «Загрузка справочника UEX…». Цены грузятся дольше справочника; ход виден в шапке («UEX 23/57»), а таблица терминала заполняется по ходу загрузки. Если загрузка не удалась, окно показывает ошибку и кнопку «Повторить»; оно разворачивается само, даже если мини-строка выключена. Позже при запуске справочник обновляется, если ему больше суток, а цены — если им больше часа; пока программа запущена, цены обновляются раз в час.
5. Выбери корабль: шестерёнка в шапке окна → группа «Корабль и поиск» → «Корабль» (список появляется после загрузки справочника) или вручную «Вместимость, SCU». Пока вместимость равна нулю (так по умолчанию), ROI не считается: столбец ROI в таблице пуст (подсказка в его заголовке: «Укажи корабль в настройках — без вместимости ROI не считается»), а в секции «Варианты» написано «Укажи корабль в настройках» с кнопкой «Открыть настройки». В той же группе — «Система» и «Бюджет, UEC».

Обновление: закрой программу («Выход» в меню значка) и запусти новый установщик. Он увидит установленную версию и предложит «Удалить перед установкой» или «Не удалять» (в английской версии «Uninstall before installing» / «Do not uninstall»). Данные при этом остаются: они лежат вне папки программы и удаляются только отметкой «Удалить данные приложения» (см. ниже).

Чтобы удалить программу, открой «Параметры» → «Приложения» → «Установленные приложения» (Windows 11) или «Приложения и возможности» (Windows 10). Окно удаления содержит отметку «Удалить данные приложения» (в английской версии «Delete the application data»). По умолчанию она не отмечена; если её отметить, будут удалены и твоя база, и резервные копии, и логи (см. «Где лежат данные»).

## Как пользоваться

### Окно

- Свёрнутое окно — мини-строка: одна строка в углу экрана (по умолчанию сверху справа). Клик по ней разворачивает окно, значок «минус» в развёрнутом окне сворачивает.
- Развёрнутое окно само сворачивается, когда курсор ушёл с него и прошло время из настройки «Сворачивать через, с» (по умолчанию 40 с, `0` — не сворачивать).
- Окно двигается за зацеп — точки слева в строке. Перетащенное окно привязывается к верхнему краю и к левой или правой стороне экрана (к той, что ближе), поэтому развёрнутое окно раскрывается вниз от места, где была строка. Нижние углы можно выбрать в «Настройки» → «Окно» → «Угол экрана». Замок рядом с настройками закрепляет окно: закреплённое окно за зацеп не двигается.
- Без мини-строки (настройка «Показывать мини-строку») свёрнутое окно скрыто: его открывает значок в трее или назначенная клавиша.
- Закрыть программу: пункт «Выход» в меню значка в трее или кнопка «Выход» в «Настройки» → «Данные».

### Настройки

Настройки открывает значок шестерёнки в шапке. Шесть групп:

- «Корабль и поиск»: корабль, «Вместимость, SCU» (от неё зависит объём закупки и сам расчёт ROI), «Система», «Бюджет, UEC».
- «Свежесть цен»: до какого возраста цена считается горячей, тёплой и остывающей — поля «Горячая до, мин», «Тёплая до, мин» и «Остывает до, мин» (по умолчанию 60 / 180 / 240 минут: это границы возраста, а не длительности по очереди); старше последней границы цена считается холодной.
- «Расчёт маршрутов»: «Скорость квантума, тыс. км/с», «Накладные на рейс, мин», «Накладные на пустой перелёт, мин», «Число вариантов», «Полное пополнение склада, мин» и «Выделять ROI от, %» (порог выделения строк таблицы, см. ниже).
- «Клавиши»: три необязательные клавиши (см. «Клавиши»).
- «Окно»: «Угол экрана», «Ширина окна, px», «Сворачивать через, с», «Прозрачность», «Показывать мини-строку».
- «Данные»: «Уровень журнала», «Открыть папку логов», «Обновить справочник», «Выход».

### Локация

- В поле «Локация…» набери три буквы названия терминала и нажми `Enter` (берётся верхний вариант) или выбери стрелками. Это только меняет, какой терминал показан.
- Кнопка «Я здесь» (она появляется, когда показан не тот терминал, где ты находишься) делает показанный терминал текущей локацией. Текущая локация меняется и сделкой: записанные «Купил», «Продал» и продажа без закупки делают терминал сделки текущей локацией (если запись не удалась, локация остаётся прежней). От текущей локации считаются маршруты.

### Таблица терминала

- Секция «Терминал» показывает товары выбранного терминала. Переключатель «Купить · N» / «Продать · N»: что здесь можно купить и что здесь можно продать. Переключатель, кнопка с лупой и кнопка «+ цена» стоят в заголовке только развёрнутой секции «Терминал»; у свёрнутой в заголовке только слово «Терминал» и название терминала.
- Клик по строке раскрывает её. В раскрытой строке два поля — цена (UEC за SCU) и количество (SCU) — и кнопки: «Где продать» и «Купил» на стороне покупки, «Где купить» и «Продал» на стороне продажи. Цена записывается, когда поле теряет фокус или нажат `Enter`.
- Кнопка «+ цена» открывает быстрый ввод: товар, цена, количество, `Enter`.
- Значок рядом с ценой говорит, чья она и насколько свежая. Закрашенный квадрат — твоя цена: горячая, тёплая, остывает или холодная. Пустой квадрат — данные UEX. Пороги свежести (по умолчанию 60 / 180 / 240 минут) меняются в «Настройки» → «Свежесть цен».
- Треугольник у цены показывает, куда сдвинулась твоя цена с прошлой записи. Зелёный — сдвиг в твою пользу, красный — против.
- Восклицательный знак у цены: цена далеко от истории UEX, проверь цифру.

### Выгода в таблице и «что везти сюда»

- В таблице есть столбец ROI — лучшая выгода для этого товара. На стороне «Продать» это лучший вариант «купить где-то и привезти сюда», на стороне «Купить» — лучший вариант «купить здесь и отвезти куда-то». Считается по данным на твоём компьютере, без запросов к UEX. Подсказка у числа говорит, откуда или куда везти и по каким ценам.
- Ячейка ROI пуста, если для товара нет варианта, который окупается при текущих фильтрах (система, бюджет, вместимость, наличие товара). Пока корабль не выбран (вместимость 0), пуст весь столбец: см. шаг 5 в «Установка и первый запуск». ROI выше 999 % показан как «999+», точное число — в подсказке.
- Строка, у которой ROI не ниже порога, выделена цветной полосой слева. Порог — «Настройки» → «Расчёт маршрутов» → «Выделять ROI от, %»: целое число от 0 до 500, по умолчанию 50. `0` выделяет каждую строку, которая в плюсе. Когда строка впервые переходит порог после ввода цены, она один раз вспыхивает.
- Клик по числу ROI в строке открывает секцию «Варианты» для этого товара. На стороне «Продать» она называется «Где купить <товар> для <терминал>», на стороне «Купить» — «Куда везти <товар> с <терминал>». Заголовок после клика по ROI заканчивается ценой строки (твоей, а если своей нет — справочной): « · продажа 5 088» на стороне «Продать», « · покупка 2 240» на стороне «Купить» (так же после кнопок «Где продать» и «Где купить» в раскрытой строке). У поиска по всем товарам цены в заголовке нет.
- Кнопка с лупой в заголовке секции «Терминал» (рядом с «+ цена») ищет сразу по всем товарам терминала. Подсказка кнопки на стороне «Продать»: «Что везти сюда: лучшие варианты по всем товарам, которые здесь покупают»; на стороне «Купить»: «Куда отсюда: лучшие варианты по всем товарам, которые можно купить здесь». Секция «Варианты» после этого называется «Где купить для <терминал>» (сторона «Продать») или «Куда везти с <терминал>» (сторона «Купить»).

### Маршрут

- Кнопка «Маршрут» показывает лучшие варианты из текущей локации в секции «Варианты». Если текущая локация не указана, программа просит сначала нажать «Я здесь».
- Сортировка: «UEC/ч» или «ROI». «и рядом» есть только у поиска «Куда везти …»: он добавляет закупку на других точках той же планеты. «все товары» — искать по всем товарам точки, когда варианты показаны для одного товара.
- Клик по варианту раскрывает его: объём, вложение, прибыль, худший исход, время, число твоих рейсов, расстояние.
- ROI окрашен по ступеням: от 30 % и выше — зелёный, от 15 % — светло-зелёный, от 5 % — оранжевый, от 0 % — серый, ниже нуля (убыток) — красный.
- Кнопка «Цель» в раскрытом варианте делает его целью рейса. «Снять цель» (или крестик в заголовке секции «Рейс») убирает цель.

### Рейс

- Первая покупка («Купил») начинает рейс и запускает таймер. Секция «Рейс» показывает груз, три фазы — «Погрузка», «Полёт», «Выгрузка» — и вложения, выручку, прибыль, ROI и UEC/ч (до конца рейса это ожидаемый результат). UEC/ч в секции и в мини-строке («≈ 273k/ч») — одно и то же число, и оно показано только когда известно время рейса: известно время полёта до цели (по твоей медиане или по расстоянию) или уже нажато «Прилетел». Пока время неизвестно, в секции на месте UEC/ч прочерк, а в мини-строке числа нет; прибыль и ROI показаны.
- Кнопки «Взлетел» и «Прилетел» отмечают фазы. Они есть и в мини-строке, и на них можно назначить клавиши.
- «Продал» продаёт товар из трюма. Продажа последнего товара закрывает рейс и сбрасывает цель.
- «Груз потерян» закрывает рейс как потерянный и списывает груз (с подтверждением).
- Продажа без закупки: если товара нет в учтённом трюме (он куплен до запуска программы, добыт или собран), «Продал» не отказывает, а записывает доход без закупки. Количество вводишь ты, вложение — 0, ROI не показывается. Такая запись не трогает идущий рейс, попадает в историю («продажа без закупки») и в заработок сессии, но не в рейтинг маршрутов и не в медианы времени.
- В секции «Рейс» для товара из трюма, у которого на показанном терминале есть твоя не холодная цена продажи, программа сравнивает «продать здесь» с вариантами «лететь дальше» (прибыль, UEC/ч, время в пути).

### Сменил сервер

- Кнопка со стрелками в шапке окна. Нажимай её, когда сменил сервер игры: цены на новом сервере могут быть другими. После подтверждения («Да, сменился») все твои цены до этой минуты считаются холодными, и расчёт опирается на справочные.
- Кнопка спрашивает подтверждение, чтобы случайный клик не охладил все цены.

### Цены UEX

- Надпись «UEX 12 мин» в шапке показывает, как давно загружены цены. Это кнопка: клик запускает обновление цен сейчас, а надпись на время обновления показывает его ход («UEX 23/57»). Надпись «UEX офлайн 3 ч» (цветом предупреждения) значит, что последнее обновление не удалось, а число — возраст тех цен, на которых программа считает сейчас (в том же виде, что у «UEX 12 мин»); полная фраза с датой — в подсказке. Если загруженных цен нет совсем, надпись такая: «UEX недоступен».
- Раз в час цены обновляются сами, пока программа запущена. Кнопка «Обновить справочник» в «Настройки» → «Данные» обновляет списки терминалов, товаров и кораблей.

### Мои маршруты и заработок за сессию

- Секция «Мои маршруты» показывает твои рейсы: «Маршруты» (по UEC в час), «История» (все рейсы, новые сверху), «Сессии».
- Сессия — это серия записей без пауз дольше двух часов. Прибыль текущей сессии видна в мини-строке без рейса («сессия +1,24M») и в заголовке свёрнутой секции «Мои маршруты» вместе с доходом в час. Когда секция развёрнута, сессии видны на вкладке «Сессии».

## Клавиши

В «Настройки» → «Клавиши» можно назначить три действия:

- «Развернуть и свернуть окно»;
- «Отметка «Взлетел»»;
- «Отметка «Прилетел»».

По умолчанию ничего не назначено. Запись клавиши: `F8`, `Ctrl+Alt+T`, `Shift+F9`. Допустимы `F1`–`F24`, `ScrollLock`, `Pause`, `Insert`, `Home`, `End`, `PageUp`, `PageDown`, а также буква или цифра вместе с `Ctrl` или `Alt`. Модификаторы `Ctrl`, `Alt` и `Shift` пишутся в любом порядке и любым регистром.

- Модификаторы должны совпасть точно: клавиша `F8` не сработает, пока зажат `Ctrl`, а `Ctrl+Alt+T` — пока зажат ещё и `Shift`.
- Одну клавишу нельзя назначить двум действиям: программа ответит «Эта клавиша уже назначена другому действию».
- Если клавиша не принята, причина написана рядом с полем.
- Нажатие назначенной клавиши доходит и до игры, как любое другое.

## Если что-то не так

- Звук игры глохнет, когда окно берёт клавиатуру (ввод в поле). В настройках игры включи звук в фоне, пока окно игры не активно.
- UEX не отвечает. Проверь, открывается ли сайт UEX в браузере: из некоторых сетей он доступен только через VPN. Программа при этом работает на твоих и уже загруженных данных, а в шапке написано «UEX офлайн …» с возрастом этих данных (подсказка называет и дату).
- Курсор появляется, когда крутишь камеру при развёрнутом окне. Это известное замечание: игра прячет курсор, но он продолжает двигаться, и над окном программы Windows показывает стрелку. Пока окно не нужно, держи его свёрнутым.
- После обновления окно раскрывается вниз. Один раз перетащи его за зацеп на нужное место: положение сохранится в настройках.
- Нужен лог для отчёта об ошибке: «Настройки» → «Данные» → «Открыть папку логов». Приложи файл `sctrade.log`. В нём есть пути к папкам с именем пользователя Windows, версия Windows, размер экрана, идентификаторы терминалов и цены, названия назначенных клавиш и числовой номер окна, у которого была клавиатура до того, как её взяло окно программы; заголовков чужих окон, имён и номеров чужих процессов нет. «Уровень журнала» там же: по умолчанию `debug`.

## Где лежат данные

- База (настройки, твои цены, рейсы, справочник UEX): `%APPDATA%\com.sctrade.app\sctrade.db`.
- Резервные копии: `%APPDATA%\com.sctrade.app\backups\sctrade-ГГГГММДД-ЧЧММСС.db`. Копия делается при каждом запуске, если база уже есть. Хранятся пять последних. Время в имени — UTC.
- Логи: `%LOCALAPPDATA%\com.sctrade.app\logs\sctrade.log`. Файл ротируется при 5 МБ, всего хранится до пяти файлов. Время в строках лога местное.
- Лог рядом с программой: если рядом с `sc-trade.exe` положить пустой файл `portable.flag`, те же строки пишутся ещё и в `sc-trade.log` рядом с exe. Это не делает программу переносной: база остаётся в папке выше.

## Сборка из исходников

Нужно:

- Node.js 24 и npm 11 (на них разрабатывалось; в проекте `@types/node` 24);
- Rust 1.90 или новее (поле `rust-version` в `src-tauri/Cargo.toml`), редакция 2024;
- сборочные инструменты Microsoft C++ и WebView2, как для любого приложения на Tauri 2.

Команды:

- `npm ci` — поставить зависимости;
- `npm run tauri dev` — запустить программу в режиме разработки;
- `npm test` — тесты (vitest);
- `npm run check` — проверка типов (svelte-check);
- `cargo test --manifest-path src-tauri/Cargo.toml` — тесты Rust;
- `npm run build` — сборка интерфейса (`dist`);
- `npm run tauri build` — установщик: `src-tauri/target/release/bundle/nsis/SC Trade_0.1.0_x64-setup.exe`, программа — `src-tauri/target/release/sc-trade.exe`. При первой сборке Tauri скачивает NSIS.

Интерфейс можно смотреть в браузере без Tauri и без игры (нужен установленный Edge или Chrome):

- `npm run preview:ui` — сервер просмотра и адрес страницы со списком сцен;
- `npm run preview:shot -- --scene expanded` — снимок сцены в PNG (`--help` показывает все параметры);
- `npm run preview:sweep` — прогон всех сцен и страниц галереи; в конце должно быть «all passed».
